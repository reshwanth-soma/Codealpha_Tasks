# Web Scraping Using Python

## 📌 Project Overview
This project demonstrates how to perform web scraping using Python to extract data from a public website. The extracted information is processed, structured, and saved as a CSV dataset for analysis and reuse.

---

## 🎯 Objectives
- Access a public website using Python
- Parse HTML content efficiently
- Extract relevant data accurately
- Organize scraped data into a structured format
- Save the data as a CSV file

---

## 🛠️ Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Jupyter Notebook

---

## 📂 Project Structure
Task_1_Quotes_to_Scrape.ipynb # Main Jupyter Notebook
quotes_dataset.csv # Extracted dataset
task1_summary.pdf # Task explanation (PDF)
README.md # Project documentation

---


## ⚙️ Methodology
1. **Accessing the Website**  
   A request is sent to the target website URL to retrieve the HTML content.

2. **Parsing HTML Content**  
   BeautifulSoup is used to parse and structure the HTML for easy navigation.

3. **Extracting Relevant Data**  
   Specific HTML tags and classes are identified to extract quote text and related data.

4. **Organizing the Data**  
   Pandas is used to store the extracted information into rows and columns.

5. **Saving the Dataset**  
   The final structured data is exported as a CSV file.

---

## 📊 Output
- A clean and reusable CSV dataset containing scraped quotes
- Well-documented and readable Python code
- Structured task explanation in PDF and format
