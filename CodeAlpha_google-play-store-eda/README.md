# Exploratory Data Analysis – Google Play Store Apps

## 📌 Project Overview
This project is completed as part of the **CodeAlpha Data Analytics Internship – Task 2**.  
The objective of this task is to perform exploratory data analysis (EDA) on Google Play Store data to identify patterns, trends, and insights related to mobile applications.

---

## 🎯 Project Objectives
- Explore Google Play Store app data
- Clean and preprocess the dataset
- Analyze app categories, ratings, and installs
- Understand user review sentiment trends
- Visualize key insights

---

## 📂 Dataset Information
Two datasets are used in this project:

1. **googleplaystore.csv**  
   - Contains app-level details such as category, rating, reviews, installs, type, price, and content rating

2. **googleplaystore_user_reviews.csv**  
   - Contains user reviews and sentiment polarity

These datasets are commonly used for EDA and machine learning practice.

---

---

## 🧪 Methodology
1. Load and inspect datasets  
2. Handle missing values and incorrect data types  
3. Perform descriptive statistical analysis  
4. Analyze app distribution by category and installs  
5. Explore ratings and user review sentiment  
6. Visualize trends using charts and graphs  

---

## 📊 Analysis Performed
- Category-wise app distribution
- Rating distribution and averages
- Install count analysis
- Free vs Paid apps comparison
- Sentiment polarity analysis from user reviews

---

## 📈 Visualizations
- Bar charts for category distribution
- Histograms for ratings
- Box plots for installs and reviews
- Count plots for app types
