# Data Visualization Using Power BI

## 📌 Project Overview
This project is completed as part of the **CodeAlpha Data Analytics Internship – Task 3**.  
The objective of this task is to convert raw sales data into meaningful and interactive visualizations using **Power BI**.

The dashboard provides insights into sales performance, customer distribution, category-wise trends, and regional contribution.

---

## 🎯 Project Objectives
- Analyze raw sales data
- Create key performance indicators (KPIs)
- Design interactive visualizations
- Enable data-driven business insights

---

## 📂 Dataset Information
- Dataset Name: `train.csv`
- The dataset does **not** include Profit or Quantity columns
- Analysis is based on:
  - Order ID
  - Order Date
  - Customer ID
  - Category
  - Sub-Category
  - Region
  - Segment
  - Sales

---

## 🛠️ Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- CSV Dataset

---

## 📐 Measures Created
- **Total Sales** – Sum of Sales
- **Total Orders** – Count of Order ID
- **Total Customers** – Distinct count of Customer ID
- **Average Sales per Customer** – Total Sales / Total Customers

---

## 📊 Visualizations Created
- KPI Cards for overall performance metrics
- Bar Chart: Sales by Category
- Column Chart: Sales by Sub-Category
- Line Chart: Sales Trend Over Time
- Pie / Donut Chart: Sales Distribution by Region
- Table View: Category, Sub-Category, and Sales
- Slicers for Region, Category, and Segment

---

## 📈 Dashboard Overview
The dashboard is designed with KPI cards at the top followed by comparison and trend-based charts.  
Interactive slicers allow users to filter data dynamically and explore insights easily.

---

## 🔍 Key Insights
- Identifies top-performing categories and regions
- Shows sales growth trends over years
- Highlights customer value through average sales per customer
