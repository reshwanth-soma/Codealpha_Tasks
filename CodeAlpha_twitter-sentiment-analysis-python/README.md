# Sentiment Analysis Using Twitter Data

## 📌 Project Overview
This project is completed as part of the **CodeAlpha Data Analytics Internship – Task 4**.  
The objective of this task is to analyze social media reviews and classify public opinion using sentiment analysis techniques.

Twitter data is used strictly according to the internship guidelines.

---

## 🎯 Project Objectives
- Analyze social media text data
- Classify sentiments into positive, negative, and neutral
- Understand public opinion trends
- Visualize sentiment distribution

---

## 📂 Dataset Information
- Dataset Name: `twitter.csv`
- Source: Kaggle (Twitter Sentiment Dataset)
- Each row represents a tweet
- Analysis is performed on the tweet text column

---

## 🛠️ Tools & Technologies Used
- Python
- Google Colab
- Pandas
- VADER Sentiment Analyzer
- Matplotlib

---

## 🧠 Methodology
1. Load the Twitter dataset into Google Colab  
2. Perform basic text preprocessing  
3. Apply VADER sentiment analysis to calculate polarity scores  
4. Classify tweets as Positive, Negative, or Neutral based on compound score  
5. Summarize results and visualize sentiment distribution

---

## 😊 Sentiment Classification
- **Positive**: Tweets with favorable opinions  
- **Negative**: Tweets with unfavorable opinions  
- **Neutral**: Tweets with no strong emotional tone  

---

## 📊 Visualization
- Bar chart showing distribution of:
  - Positive tweets
  - Negative tweets
  - Neutral tweets

---

## 🔍 Key Insights
- Provides an overview of public opinion on social media
- Helps identify dominant sentiment trends
- Useful for marketing analysis and decision-making
